# Abaqus AI — Community V1.0

**Mohamed Amr Software** — Engineering Ideas into Software

**Repository status:** Initial documentation. Full installation package and source files have not yet been uploaded to this repository.

Independent integration kit based on [Abaqus-Control-MCP](https://github.com/Whfkl/Abaqus-Control-MCP), supplied upstream 2.0.0 (MIT). Read-only ping and session metadata; no arbitrary Python or solver tools.

## Security and testing

The prepared V1.0 package uses loopback-only communication and an installation-specific authentication token. The package was tested with a simulated Abaqus environment; production compatibility across Windows installations is not yet certified. Do not publish installed configuration files, tokens, receipts or backups. This is not an official Dassault Systèmes or Anthropic product and does not include their software licenses.
